# PolyTAS

Tool-assisted speedrunning editor for Polytrack.

## Structure
- `extension/` Chrome extension (MV3) with Picture-in-Picture support.
- `standalone/` Original standalone HTML version (kept for reference).

## Use the Chrome extension
1) Open Chrome and go to `chrome://extensions`.
2) Enable **Developer mode**.
3) Click **Load unpacked** and select `extension/`.
4) Open Polytrack in a tab.
5) Click the PolyTAS extension icon and choose **Open PiP Window**.
6) In the PiP window, click **ATTACH GAME** while the Polytrack tab is active.

## Standalone
Open `standalone/polytas.html` directly in a browser. (This version does not use a real PiP window.)
