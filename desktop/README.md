# PolyTAS Desktop

Electron-based desktop app for PolyTAS with an embedded game view and live splice preview.

## Run (dev)

```bash
cd /Users/yannis/Documents/Infomaticaprojecten/PolyTAS/desktop
npm install
npm run dev
```

## Notes
- Set the game URL in the right-side Game Preview panel.
- Edits automatically trigger a live replay preview when Live Preview is enabled.
